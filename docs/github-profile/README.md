# Data Analytics & Business Intelligence

I build portfolio projects that turn sales and operational data into clear business questions, reproducible analysis, and Power BI reports.

**Open to Data Analyst, Business Intelligence Analyst, and Power BI Developer opportunities.**

My projects focus on retail profitability, restaurant sales performance, and healthcare billing. I connect the numbers to decisions, document metric definitions, and distinguish findings from recommendations.

## Skills demonstrated in this portfolio

- **SQL:** aggregations, CASE expressions, CTEs, window calculations, and profitability comparisons.
- **Power BI:** multi-page reporting, KPI presentation, sales and operational breakdowns, and report navigation.
- **Python and SQLite:** workbook validation, repeatable database loading, query exports, and automated checks.
- **Business analysis:** defining the data grain, checking financial consistency, explaining findings, and identifying the evidence needed for a recommendation.
